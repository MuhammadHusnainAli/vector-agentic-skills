# Demo Script Template

## Timing maths

- Spoken pace in demos: about 130-150 words per minute, slower while clicking.
- Each beat: 30-90 seconds. A 10-minute slot: about 5 minutes of demo, 5 of discussion.
- Words budget: 5 minutes x 130 wpm = about 650 words including pauses for clicks; cut to 500.

## Script table

| Time | Beat | Screen / click | Talk track |
|------|------|----------------|------------|
| 0:00 | Ask | Title slide | "We're asking for a decision on X today." |
| 0:20 | User | Persona slide | Who, situation, goal |
| 0:50 | Problem | Clip / metric | Evidence of the pain today |
| 1:40 | New experience | Prototype S01 -> S05 | The task, step by step, in the user's terms |
| 4:00 | Outcome | Prototype end screen / slide | What changes for the user and the business |
| 4:30 | Framing | Slide | What's real, what's mocked, what's undecided |
| 4:50 | Ask | Slide | Repeat the ask with options |
| 5:00 | Discussion | | Prepared questions to prompt input |

## Worked example: 10-minute executive demo

**Decision:** approve two engineers for Q1 to build self-serve refunds.

| Time | Beat | Screen / click | Talk track |
|------|------|----------------|------------|
| 0:00 | Ask | Title | "In ten minutes I'd like a yes or no on staffing self-serve refunds in Q1." |
| 0:20 | User | Photo + one line | "This is Priya. She runs a small shop on our platform, and refunds take her 20 minutes each." |
| 0:45 | Problem | Support dashboard slide | "Refund requests are 31% of support tickets. Average handling time is 2 days. Here's Priya in our research session." (15 s clip) |
| 1:40 | Task start | S01 Orders list | "Priya gets a refund request from a customer. Today she'd email support. Now she opens the order." Click order #1042. |
| 2:10 | Refund | S02 Order detail -> Refund | "She picks the items, the reason, and sees exactly what the customer gets back, including shipping." Click Refund. |
| 2:50 | Confirmation | S03 Review -> Confirm | "One review screen, because refunds can't be undone." Click Confirm. |
| 3:20 | Outcome | S04 Done + customer email | "The customer is notified automatically. Priya is back to work in under a minute." |
| 3:50 | Impact | Slide | "If 60% of refund tickets go self-serve, that's about 1,900 fewer tickets a month." |
| 4:20 | Framing | Slide | "This is a clickable prototype: refunds, emails and numbers are mocked. Payment provider support is confirmed for card refunds; bank transfers are an open question." |
| 4:45 | Ask | Slide | "Two engineers for Q1. Option B: one engineer, cards only, ships a month later." |
| 5:00 | Discussion | | "What would make you confident in the 60% estimate?" |
