# Naming Convention

## Structure

```
<prefix>_<subject>[_<descriptor>][_<variant>][_<size>][_<state>][_<theme>]
```
All lowercase, words joined with underscores, no spaces, hyphens or special characters. This is valid on Android and fine
on iOS and web, so one name works everywhere.

| Part | Examples | Notes |
|------|----------|-------|
| prefix | `ic` icon, `illus` illustration, `img` photo/image, `logo`, `bg` background, `anim` animation, `ic_launcher` app icon | Groups assets in file lists |
| subject | `arrow`, `cart`, `empty_inbox`, `hero_home` | What it shows, not where it's used |
| descriptor | `left`, `outline`, `filled`, `round` | Visual distinctions |
| variant | `small`, `wide`, `square`, `alt` | Crops or layouts of the same subject |
| size | `16`, `24`, `48` | Design size in dp/pt/px, for icons drawn per size |
| state | `selected`, `disabled`, `pressed` | Prefer code-driven states over state assets |
| theme | `dark`, `light` | Only on platforms without appearance-aware catalogs |

## Examples

| Good | Bad | Why |
|------|-----|-----|
| `ic_arrow_left_24` | `Arrow Left.png` | Spaces, case, no prefix |
| `ic_cart_outline_24` | `ic-cart-outline-24` | Hyphens are illegal in Android resource names |
| `illus_empty_inbox` | `empty-state-v2-final` | Versions belong in version control |
| `img_hero_home_wide` | `homepage_banner_desktop_1440@2x` | Scale belongs in folders/catalog slots, not names |
| `logo_wordmark_dark` | `LogoWhite` | Name by role/theme, not colour |

## Scale and density suffixes

- iOS: the `@2x`/`@3x` suffixes are added by export (`ic_cart_24@2x.png`) and absorbed by the asset catalog.
- Android: same file name in each `drawable-<density>/` folder; no suffix.
- Web: width suffix for srcset (`img_hero_home-800.avif`), generated by the build pipeline.

## Rules

- One subject vocabulary shared with the design system (icon names match the icon library's names).
- Don't encode usage ("checkout_button_icon"): assets get reused.
- Don't encode colour ("ic_close_red"): colour comes from tokens via `currentColor` / tint.
- Keep names stable: renames break code references; deprecate instead.
