# Common English Pronunciation Difficulties by First Language

Typical, well-documented tendencies (see Swan and Smith, *Learner English*, 2nd ed., and Jenkins' Lingua Franca
Core). Individuals vary: listen to the learner before assuming. Priority: **high** = often affects
intelligibility (Lingua Franca Core features: most consonants, vowel length, consonant clusters at the start of
words, nuclear stress); **medium** = noticeable; **low** = accent feature, rarely a problem.
