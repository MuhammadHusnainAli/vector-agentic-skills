# Bottom-up Listening: Decoding Activities

Many listening failures are not about vocabulary but about recognising known words in connected speech.
After the comprehension tasks, spend 5-10 minutes on decoding using a short section of the recording.

## Connected speech features

| Feature | Example (written -> spoken) | Activity |
|---------|-----------------------------|----------|
| Weak forms | *to, for, of, and, can, was* -> /tə, fə, əv, ən, kən, wəz/ | Count the words in a fast phrase; gap-fill of function words |
| Linking (consonant-vowel) | *an apple* -> /ənæpl/; *turn it off* -> /tɜːnɪtɒf/ | Mark links on the transcript; dictation of linked phrases |
| Elision | *next day* -> /neks deɪ/; *last night* -> /lɑːs naɪt/ | Which sound disappears? |
| Assimilation | *ten boys* -> /tem bɔɪz/; *don't you* -> /dəʊntʃu/ | Listen and choose what was said |
| Intrusion | *go on* -> /gəʊwɒn/; *I agree* -> /aɪjəgriː/ | Notice and repeat |
| Contractions | *I would have* -> /aɪdəv/ | Expand contractions in a transcript |
| Chunks | *I don't know* -> /aɪdənəʊ/; *going to* -> /gənə/ | Match chunk recordings to written forms |

## Activities (short, after the main tasks)

| Activity | How |
|----------|-----|
| Micro-dictation | Play one fast sentence 3-4 times; learners write every word; compare with transcript |
| Word counting | How many words in this phrase? (learners often hear 3 for 6) |
| Gap-fill of function words | Transcript extract with articles, prepositions, auxiliaries gapped |
| Transcript reading while listening | Underline words that are hard to hear; discuss why |
| Shadowing | Learners speak along with the recording a fraction behind; builds rhythm |
| Spot the difference | Transcript with 5 changed words; learners correct while listening |
| Slow-fast comparison | Teacher says the phrase slowly then naturally; learners notice changes |
| Stress spotting | Mark the stressed words in a sentence; notice that they carry the meaning |

## Listening strategies to teach explicitly

- Predict before listening (context, speakers, likely words).
- Listen for stressed words; they carry the content.
- Use what you understood to guess what you missed.
- Do not stop at an unknown word; keep listening.
- Check predictions after each play.

## Using the transcript well

Give the transcript only after the comprehension tasks. Use it for decoding work, language focus and as a
self-study resource. Do not let learners read it during the first listening.
