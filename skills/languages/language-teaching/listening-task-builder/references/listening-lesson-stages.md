# Listening Lessons: Stages, Tasks and Plays

Listening is harder than reading: learners cannot go back, speech is fast and connected, and words they know
on paper may be unrecognisable in speech. Tasks must be set **before** each listening.

## Stages

| Stage | Purpose | Example |
|-------|---------|---------|
| Lead-in | Context, interest, predictions | Photo of a hotel reception: what do people say here? |
| Pre-teach (max 4-6 items) | Words that block the tasks | Reservation, key card, lift |
| Set task 1 | Gist | Where are they? Is the guest happy? |
| Play 1 | | Learners compare answers in pairs |
| Set task 2 | Specific information / detail | Room number, breakfast time, wifi password location |
| Play 2 (pause if needed) | | Pairs compare, then feedback |
| Task 3 (optional) | Inference, attitude, or a decoding task | How does the receptionist sound? Gap-fill of a short section |
| Play 3 / with transcript | Bottom-up focus | Learners read the transcript while listening; notice connected speech |
| Language focus | Useful chunks from the text | Can I see...? Here you are. |
| Response | Speaking or writing that uses the content | Role play checking in |

## Number of plays

| Level | Plays | Notes |
|-------|-------|-------|
| A1-A2 | 2-3 | Short recordings (under 2 minutes); pause between sections |
| B1 | 2 | Pause for longer detail tasks |
| B2 | 1-2 | Second play for detail |
| C1-C2 | 1 | Like real life; second play for language work |

Always let learners compare answers in pairs between plays; it lowers anxiety and shows the teacher whether
another play is needed.

## Task types

| Sub-skill | Tasks |
|-----------|-------|
| Gist | Choose the picture/title; who is speaking to whom; where; mood |
| Specific information | Complete a form, table or timetable; tick what you hear; numbers, names, times |
| Detail | Wh- questions in order of the recording; T/F; multiple choice; note-taking frame |
| Inference | Attitude, relationship, speaker's opinion, what happens next |
| Following instructions | Draw a route on a map; arrange objects; do the actions (young learners) |
| Note-taking (B2+) | Lecture notes with a partial outline; Cornell notes |

Rules: questions follow the order of the recording; questions do not need long reading while listening; answers
are short (a word, number, tick); space questions so there is time between answers in the recording.

## Speed and level

| Rate (words per minute) | Feels | Fits |
|-------------------------|-------|------|
| Under 120 | Slow, careful | A1-A2 |
| 120-150 | Moderate | A2-B1 |
| 150-180 | Natural conversation, radio | B1-B2 |
| 180+ | Fast, excited speech | B2-C2 |

`transcript_stats.py` calculates the rate. Faster recordings can still work at lower levels with gist tasks,
pauses and short segments.

## Choosing recordings

- Coursebook audio is clear but scripted; mix with semi-authentic (interviews, vlogs) and authentic recordings.
- Expose learners to different accents (UK, US, Australian, Indian, Nigerian, L2 speakers) once the task is
  familiar.
- Video helps with context but can distract on detail tasks; consider audio-only for the second play.
- Write your own script and record it with a colleague for exact targeting of language.

## Answer key

Give the answer and the timestamp where it is heard (e.g. "214 - 0:33").
