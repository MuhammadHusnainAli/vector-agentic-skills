## Receptive skills lessons (reading or listening)

| Stage | Min | Purpose |
|-------|-----|---------|
| Lead-in | 5 | Interest, schema activation |
| Pre-teach blocking vocabulary (max 4-6 items) | 7 | Remove barriers to the tasks |
| Gist task | 7 | Read or listen once for the main idea |
| Specific information / detail task | 15 | Second reading or listening |
| Inference or deduction of meaning (optional) | 6 | Deeper reading |
| Post-task: speaking or writing reacting to the text | 15 | Use the content |
| Feedback | 5 | |

## Productive skills lessons (speaking or writing)

| Stage | Min | Purpose |
|-------|-----|---------|
| Lead-in | 5 | Interest |
| Model text or recording | 8 | Show the target genre |
| Analyse the model: structure, useful language | 10 | Notice features |
| Plan / prepare | 7 | Ideas, language |
| Task (speak or write) | 15 | Fluency or accuracy focus |
| Feedback on content then language | 10 | |
| Redraft or repeat task (optional) | 5 | Improvement |

## Task-based (Willis)

Pre-task 10, task 15, planning 10, report 10, language focus (analysis and practice) 15.

## ESA (Harmer)

Engage, Study, Activate in any order: straight arrows (E-S-A), boomerang (E-A-S-A), patchwork (E-A-S-A-S-E-A).

## Choosing

| Main aim | Shape |
|----------|-------|
| New grammar or functional language, A1-B1 | PPP or guided discovery |
| Language learners half-know, B1+ | TTT or TBL |
| Reading or listening sub-skills | Receptive skills shape |
| Speaking fluency or a writing genre | Productive skills shape |
| Real-world outcome, mixed language | TBL |
