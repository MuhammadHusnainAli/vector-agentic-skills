# Teaching Language Lessons Online

## Lesson shape

| Stage | Online adaptation |
|-------|-------------------|
| Warmer | Chat waterfall (everyone types, sends together), poll, quick show-and-tell with an object |
| Presentation | Slides with annotation; short (under 5 minutes of teacher talk at a time) |
| Clarification | Whiteboard timelines; CCQs answered in chat or with reactions |
| Controlled practice | Shared doc or quiz tool; learners type; teacher sees everyone's answers |
| Freer speaking | Breakout rooms (pairs or threes) with the task pasted in; visible timer; teacher visits |
| Feedback | Whiteboard error correction; learners correct in chat |
| Close | Exit poll or quick write in the chat; homework link |

Change interaction every 5-10 minutes; online attention drops faster than in a room.

## Classroom activities that transfer well

| Activity | Online version |
|----------|----------------|
| Find someone who | Breakout rooms rotating every 3 minutes; or chat questions to named classmates |
| Spot the difference | Each learner gets their picture privately (chat or LMS) |
| Running dictation | "Dictation from a link": one learner opens the text and reads; partner types |
| Board race | Teams type words in the chat; first correct message wins |
| Back to the board | One learner turns off their screen view (or looks away); team defines the word on screen |
| Mingle | Several short breakout rounds |
| Jigsaw reading | Expert groups in breakout rooms, then mixed rooms |
| Pictionary | Whiteboard drawing |
| Role play | Breakout rooms with role cards sent privately |

## One-to-one online

- More teacher talk is natural, but keep the learner speaking at least half the time.
- Use the learner's own materials (work emails, presentations).
- Shared document as a running record of new language and corrections.
- Record short speaking tasks for self-review (with consent).

## Young learners online

- Shorter lessons (30-45 minutes) and very short activities (3-5 minutes).
- Movement breaks: TPR, "find something red in your house".
- Puppets, props and big expressions; simple visual routines.
- Parent present or nearby for the youngest; agreed rules for chat and cameras.

## Engagement and participation

- Name learners when asking questions; avoid "Anyone?".
- Use the chat for simultaneous answers so quieter learners participate.
- Give thinking time before speaking ("Think for 30 seconds, then tell your partner").
- Camera-off learners: use voice, chat and reactions; check in privately.
- End breakout rooms with a 30-second warning.

## Asynchronous work

Between live lessons: vocabulary practice on a quiz tool, voice-note speaking tasks, short writing in the LMS with
feedback, video lessons for flipped presentation so live time is for speaking.
