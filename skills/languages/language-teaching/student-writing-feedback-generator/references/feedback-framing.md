# Framing Written Feedback for Language Learners

## Principles

1. **Content and task first, language second.** Respond to the message before the errors.
2. **Selective.** Two or three focus areas are actionable; forty red marks are not.
3. **Specific.** Point to the text: "In paragraph 2 you give a reason with an example - good."
4. **Feed forward.** Say what to do next time and how.
5. **Action required.** Learners redraft, correct or log errors; feedback nobody uses is wasted.
6. **Level-appropriate language.** Feedback must be understood: simple words at A1-B1, or the learner's L1 if the
   class allows it.
7. **Balanced tone.** Genuine strengths, not empty praise.

## Structure of a comment (strength - target - action)

```
Strength: You answered all three questions in the email, and your opening is friendly and natural.
Target:   Past tense verbs - several are in the present (go, eat).
Action:   Find the four verbs marked T and change them to the past. Add them to your error log.
```

## Comment bank

### Task and content
- You covered all the points in the task.
- You covered two of the three points: remember to say when you are free.
- Your ideas are interesting and well explained with examples.
- Some ideas are not connected to the question: keep to the topic.
- Your opinion is clear from the start and in the conclusion.

### Organisation
- Clear paragraphs, each with one main idea.
- Use paragraphs: one for each point in the task.
- Good linking words (however, as a result).
- Try different linkers: you use "and" many times; try "also", "in addition", "but", "so".

### Language
- You use a good range of vocabulary for this topic (e.g. "crowded", "breathtaking").
- Try to use some new words from the unit: (list).
- Your sentences are accurate; now try longer sentences with because/although/when.
- Check verb forms after "enjoy", "want", "can" (see VF codes).

### Register and format
- Good formal opening and closing.
- This is a formal email: avoid contractions (I'm -> I am) and "Hi".

### Next steps
- Rewrite paragraph 2 using the corrections.
- Next time, check your text for T and Agr errors before you hand it in.
- Use the checklist before you submit.

## Self- and peer-check checklist (learner-facing, B1 email)

| Question | Yes / Not yet |
|----------|---------------|
| Did I answer every point? | |
| Did I start and finish correctly for this reader? | |
| Are my paragraphs clear? | |
| Did I check verb tenses? | |
| Did I check spelling of words I'm not sure about? | |
| Is my text within the word limit? | |

## Avoid

- Rewriting the whole text (learners copy without thinking).
- Grades without comments.
- Comments on handwriting or neatness instead of language.
- Comparisons with other learners.
