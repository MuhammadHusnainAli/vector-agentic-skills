# Correction Code Key

Give learners this key at the start of the course. Codes show **where** and **what kind** of error; learners
find the correction themselves, which leads to more learning than reading the teacher's correction.

| Code | Meaning | Example (coded) | Correction |
|------|---------|-----------------|------------|
| Sp | Spelling | my freinds[Sp] | friends |
| T | Tense | Yesterday I go[T] | went |
| VF | Verb form | I enjoy to swim[VF] | enjoy swimming |
| Agr | Subject-verb agreement | she like[Agr] | likes |
| WW | Wrong word | I made[WW] my homework | did |
| WF | Word form | It was a success[WF] party | successful |
| Art | Article | I went to beach[Art] | the beach |
| Prep | Preposition | arrived to[Prep] London | in |
| WO | Word order | I very enjoyed[WO] it | I really enjoyed it / I enjoyed it very much |
| ^ | Missing word | I went ^[^] Paris | to |
| X | Extra word | I called to[X] my mum | (delete to) |
| P | Punctuation | Its[P] cold | It's |
| C | Capital letter | in january[C] | January |
| Reg | Register | Hey Mr Smith[Reg] (formal email) | Dear Mr Smith |
| ? | Meaning unclear | The life is a road of colours[?] | (rephrase) |
| // | New sentence or paragraph | ...it was hot // we went | Split |

## Marking with codes

- Code only what the learner can correct: errors in language they have studied. Reformulate (write the correct
  version) for language above their level.
- Choose 2-3 focus areas per text (often the most frequent patterns) rather than coding every error.
- Underline without a code for higher levels or for errors the learner knows well (they find the type too).
- Add a positive comment first and a content comment: is the message clear, is the task done?

## Using coded feedback in class

1. Return texts with codes; learners correct in pairs using the key (10 minutes).
2. Learners record their top errors in a personal error log (error, correction, rule).
3. Redraft (or rewrite one paragraph) and highlight the corrections.
4. Teacher checks the corrections, not the whole text again.

## Electronic marking

In a word processor use comments or highlight colours per code; in an LMS, a rubric plus inline comments; keep the
same code key so learners recognise it.
